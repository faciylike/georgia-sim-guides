## 核心运营商：二选一就够用了

　　格鲁吉亚的电信市场挺有意思，主要玩家就两个：**Magti** 和 **Beeline**（以前叫Geocell）。说真的，对旅行者来说，在这两家之间做选择，有点像在巧克力和冰淇淋之间纠结——都不错，看你更看重什么。

　　Magti的信号覆盖公认更好，尤其是往卡兹别克山区或者西格鲁吉亚那些偏远点儿的地方跑，它的优势就显出来了。网速也通常更稳更快，但价格嘛，自然要贵上那么一点点。Beeline呢？它可是性价比之王，在城市里用着完全没问题，流量套餐给得也大方。如果你大部分时间都在第比利斯、巴统、库塔伊西这些城市转悠，选它可能更划算。

　　（话说回来，我个人的偏好是Magti。多花那几拉里，买来在山路上还能顺畅发朋友圈的踏实感，我觉得值。）

## 2025年套餐价格与选择

　　价格这东西每年都可能变，但2025年初的行情大致是这样。机场柜台、市区营业厅、甚至路边小卖部（这叫“小卖部”可能有点夸张，但很多杂货店确实都卖卡）都能买到。

**预付卡（Prepaid SIM）** 依然是主流，即买即用，不用实名（至少旅游卡暂时还不需要，政策这事儿得随时留意）。

*   **Magti**: 最受欢迎的旅游套餐大概在25-35拉里（约合人民币70-100元），通常包含10GB+的全国流量、一些本地通话时间和短信。它的“无限社交套餐”挺有意思，专门针对WhatsApp、Facebook这些App，几乎不限量，适合重度社交用户。
*   **Beeline**: 20-30拉里（约合人民币55-85元）就能拿下15GB甚至更多的通用流量套餐。它经常有些促销活动，比如夜间流量加倍之类的，买的时候可以多问一嘴。

　　想象一下，你正站在“母亲堡垒”山顶，想直播一下第比利斯全景，却发现流量包见底了……所以，根据自己的用量，宁可买大一点的套餐。流量这玩意，总是用着用着就没了。

## 频段、APN与设备兼容：搞定这步才能上网

　　这可是最容易踩坑的地方！卡插进去，有信号却没网络？99%是APN没设置对。

　　格鲁吉亚主要使用4G LTE网络，频段是**Band 3 (1800MHz)** 和 **Band 7 (2600MHz)**。绝大多数国内带来的手机都支持，但如果你用的是非常老旧的机型或者某些特定版本的手机，最好提前查一下。

**买到卡后，第一件事不是插卡，而是找店员帮你设置APN！** 或者自己手动设置：
- Magti APN: `internet.magti`
- Beeline APN: `internet.beeline.ge`

　　（我就有过在营业厅门口折腾了半小时APN的经历，后来才发现大小写输错了……）

　　对了，如果你是双卡手机，记得把格鲁吉亚卡设为主上网卡。安卓和iOS的设置路径不太一样，但都不难找。
